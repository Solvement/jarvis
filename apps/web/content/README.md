# 学习圈发布

`learning-circle.json` 只放用户明确同意公开的学习笔记快照；不是飞书全库同步目录。

1. 用官方 CLI 以 user 身份读取指定文档最新正文，使用 `--doc-format xml --detail full` 保留文字颜色、高亮、加粗和删除线。完整响应保留在公开目录以外；只读 Markdown 会丢失颜色语义，不可用它替代格式原件。
2. 为新笔记追加唯一 slug、日期、作者、简介、来源链接、来源版本及正文。使用 `parseFeishuRichText` 转成允许的 `richNodes`，与 `bodyMarkdown` 备用文本一同保存；不得渲染未经处理的原始 HTML。`colorLegend` 中颜色含义必须由作者确认，不能自行猜测。原条目保留；修订时保留其 slug，不覆盖其它笔记。
3. 获得发布授权的图片下载到 `public/learning-circle/<slug>/`，正文改为本站相对图片路径。不要发布凭证、认证图片链接或其它未授权文档。
4. 发布到原网站。列表地址 `/circle`；稳定分享地址 `/circle/<slug>`，不要求登录。不会自动公开飞书后续改稿。

正文保留作者当时的理解、删除线和疑问；未独立核查的转述须保留学习笔记说明。`/circle` 是公开栏目；个人书架、私人草稿和其它人的笔记仍由既有权限控制。

作者于 2026-10-20 确认：这篇笔记绿色代表自己的感想，红色代表重点。网站按原样保存，不额外增加分类标签；以后可能出现其它颜色，仍须保留原色和准确标记范围，不自行猜测语义。
