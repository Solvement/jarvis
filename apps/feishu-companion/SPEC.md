# 飞书学习搭档：本机个人版

## 使用目标

用户在飞书网页版记录学习笔记。用户在文档旁提问，助手结合这篇文档、选中文字和最近插入位置回答。用户也能通过飞书机器人提问。模型调用使用用户自己的 Codex ChatGPT 订阅登录，不回退到收费 API。

这是个人本机工具：Node 服务、Codex App Server、Chrome/Edge 扩展、飞书机器人长连接。电脑在线时运行；不部署到网站、公共服务器，不为其他人提供模型服务。AI 负责实现和验证；用户负责飞书应用授权、安装扩展及最终体验判断。

## 首版行为

1. 侧栏提问时采集当前飞书文档的已渲染正文、最近文档选区/光标及时间。明确标注这是浏览器已加载内容，不能声称覆盖尚未渲染的整篇长文。输入法候选尚未落字不保证捕获。
2. 选区在文档失去焦点后保留。文档切换、正文变化及光标重新定位不能沿用旧选区。跨段选择保留原文；折叠选区按实际节点偏移记录，不能伪造全文绝对偏移。
3. 每篇文档独立会话；机器人与侧栏使用不同会话。上下文缺失、截断或过期必须显式说明，机器人不暗中使用其他页面的内容。
4. 机器人仅处理配置的本人单聊文本，重复投递不重复调用模型。通过 `/doc <链接>` 显式绑定扩展已同步的文档；`/new` 清空当前聊天会话。
5. 本机入口绑定 127.0.0.1，凭证和上下文不进 Git。请求需本机令牌，拒绝任意网站跨域。模型只回答，不能自动编辑文档或代发其他消息。

## 验收

- 自动测试覆盖订阅身份限制、并发隔离、事件去重、越权拒绝、上下文有效期和正文完整性标记、HTTP 访问控制、App Server 响应及断连。
- 真实 Codex 登录状态检查不输出 token；一次无私人材料的真实模型问答证明订阅链路。
- 本机服务真实运行，侧栏页面可加载。扩展脚本在飞书当前页面实测正文和选区采集，或明确记为未完成。
- 飞书没有凭证时展示缺项，不宣称机器人已连接。真实消息闭环要等用户完成授权后再验收。

## 范围与恢复

此轮不实施全库索引、后台提醒或直接写回文档。全库文档/消息搜索仍由后续官方 CLI 用户授权接入。重启保留会话 ID 和去重记录；正文上下文只在本机内存暂存，重启需要重新同步。失败返回可操作原因，超时中断模型，断连不自动重复付出额度。

## 技术依据

- [Codex App Server](https://learn.chatgpt.com/docs/app-server)：官方自定义客户端接口，ChatGPT managed 登录；属于实验性接口，本机个人使用。
- [飞书 Node SDK](https://github.com/larksuite/node-sdk)：机器人长连接无需公网 webhook。
- [REA](https://github.com/morluto/rea)：分析原生程序、JS/Electron 等的工具；没有现成的飞书机器人/订阅桥接能力。首版不依赖逆向、不读取私有 token 或调用未公开接口。
