# 论文阅读方法 · 来源：S. Keshav, "How to Read a Paper"（用户提供 PDF，2026-09-06）

三遍法。每遍有明确目标，后一遍建立在前一遍之上。

| 遍 | 做什么 | 时长 | 结束时应能回答 |
|---|---|---|---|
| 第一遍 | 标题、摘要、引言；各级标题；结论；扫参考文献 | 5–10 分钟 | 五个 C：类型（Category）、关联（Context）、假设是否成立（Correctness）、贡献（Contributions）、写得清不清楚（Clarity）；并决定要不要读下去 |
| 第二遍 | 细读但跳过证明；盯图表：坐标轴标了没、有没有误差条；标记未读的相关引用 | 最多 1 小时 | 能把论文主旨和支撑证据讲给别人 |
| 第三遍 | 「虚拟重实现」：按作者的假设自己重建这项工作，与原文对照 | 新手 4–5 小时，熟手 1 小时 | 能凭记忆重建全文结构，指出隐含假设、漏引的工作、实验或分析方法的问题 |

## 对 Jarvis 的映射

- **速览 = 第一遍**。产出五个 C 里对读者有用的部分：类型、贡献、假设是否可疑，外加「为什么现在上榜」。目的之一就是决定要不要精读。
- **精读 = 第二遍 + 第三遍**。要替代读原文：图表逐张解释（含坐标、误差条、样本），关键机制按「如果我来实现会怎么做」对照原文，列出隐含假设和方法问题。这是「能给别人讲」的依据。
- 项目（仓库）没有对应的三遍法，但可类比：第一遍读 README 与文件树，第二遍读入口代码与配置，第三遍跑起来或对照文档核对声明。

精读的具体形式待与用户讨论后再定。
